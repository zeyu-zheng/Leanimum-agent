# Leanimum-agent

Leanimum-agent is a minimal bash-only assistant for Lean proofs and programs.
It searches libraries, edits files and runs compiler checks through a shell tool.

- [Quick start](quickstart.md): install and run a Lean task.
- [ReuF2F](usage/reuf2f.md): generate patches for the built-in benchmark.
- [Configuration](advanced/yaml_configuration.md): select models, prompts and budgets.
- [Execution environments](advanced/environments.md): local and container backends.
- [Output files](usage/output_files.md): predictions, trajectories and inspection.
- [Python bindings](usage/python_bindings.md): use or extend the agent in code.

ReuF2F performs independent grading; agent completion is not a proof verdict.
